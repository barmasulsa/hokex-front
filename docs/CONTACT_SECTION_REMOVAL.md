# 문의 섹션 제거 (개인정보 보호)

## 배경
개인정보 보호법 준수를 위해 행사 상세 페이지에서 문의 정보(담당자 이름, 전화번호, 이메일) 표시를 중단합니다.

## 변경 사항

### 프론트엔드
- **파일**: `hokex-front/src/pages/EventDetailPage.tsx`
- **변경**: 모든 venue 레이아웃에서 "문의" detail-item 제거
- **유지**: formatContact, formatCoexContact 함수는 코드에 남겨둠 (향후 복구 가능)

### 백엔드/크롤러
- **변경 없음**: DB의 `contact`, `manager` 필드는 그대로 유지
- **변경 없음**: 크롤러의 contact/manager 수집 로직 유지
- **이유**: 언제든 복구 가능하도록 데이터는 보존

### 스펙 문서
- **변경**: 각 전시장별 스펙 문서에 "⚠️ 기능 정지: 개인정보 보호를 위해 문의 정보는 UI에 표시하지 않음" 주석 추가
- **유지**: 문의 정보 크롤링 로직 설명은 그대로 유지

## 제거된 UI 요소

## 복구 방법

필요시 다음 단계로 복구 가능:

1. **프론트엔드**: EventDetailPage에서 주석 처리된 문의 섹션 활성화
2. **스펙 문서**: "⚠️ 기능 정지" 주석 제거
3. **재배포**: 프론트엔드만 재배포하면 즉시 복구

## 데이터 현황

- **DB**: contact, manager 필드 데이터 100% 보존
- **크롤러**: 계속해서 문의 정보 수집 중
- **API**: 문의 정보는 API 응답에 포함됨 (프론트엔드에서만 비표시)

## 법적 고려사항

- 공개된 행사 정보의 문의처는 일반적으로 개인정보가 아닌 업무용 연락처
- 하지만 담당자 이름이 포함된 경우 개인정보로 간주될 수 있음
- 안전을 위해 모든 문의 정보를 비표시 처리
