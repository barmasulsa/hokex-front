# Visitor Stats Synchronization Fix

## 문제 상황

관리자 페이지와 홈페이지가 서로 다른 방문자 통계를 표시하는 문제가 발생했습니다.

### 증상
- **관리자 페이지**: 실시간 DB 조회로 정확한 통계 표시
- **홈페이지**: 캐시 테이블 조회로 오래된 통계 표시
- 두 페이지의 숫자가 일치하지 않음

### 원인 분석
1. 관리자 페이지: `getDetailedVisitorStats()` → DB 직접 조회
2. 홈페이지: `getCachedVisitorStats()` → 캐시 테이블 조회
3. 캐시 업데이트 메커니즘 부재

## 요구사항

### 1. 단일 데이터 소스 사용
- 모든 페이지가 동일한 캐시 테이블을 사용
- 관리자/홈페이지 통계 일치 보장

### 2. 실시간 동기화
- 방문자 데이터 변경 시 즉시 캐시 업데이트
- 1분마다 자동 재계산으로 일관성 보장

### 3. 비즈니스 날짜 기준
- 새벽 4시 기준으로 날짜 구분
- 0시~3시59분은 전날로 계산

### 4. 안정적인 배포
- 기존 함수/트리거 안전하게 교체
- 에러 없이 실행 가능한 SQL 스크립트

## 성공 기준

1. ✅ 관리자 페이지와 홈페이지의 통계가 항상 일치
2. ✅ 방문자 추가 시 1분 이내 반영
3. ✅ 새벽 4시 기준 날짜 계산 정확성
4. ✅ SQL 스크립트 에러 없이 실행
