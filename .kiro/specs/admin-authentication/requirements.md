# 관리자 인증 시스템 구현

## 문제점
현재 관리자 모드는 버튼 클릭만으로 누구나 활성화할 수 있어 보안이 전혀 없습니다.
- ❌ 로그인 없음
- ❌ 비밀번호 없음
- ❌ 권한 체크 없음
- ❌ URL만 알면 누구나 행사 정보 수정 가능

## 목표
Supabase Auth를 사용한 제대로 된 인증 시스템 구축

## 요구사항

### 1. 인증 시스템
- Supabase Auth 사용
- 이메일/비밀번호 로그인
- 로그인 페이지 구현
- 로그아웃 기능
- 세션 관리 (자동 로그인 유지)

### 2. 권한 관리
- DB에 사용자 권한 저장 (is_admin 필드)
- 관리자만 데이터 수정 가능
- 일반 사용자는 읽기만 가능

### 3. UI 변경
- 로그인 전: "로그인" 버튼
- 로그인 후 (일반 사용자): 사용자 이메일 표시
- 로그인 후 (관리자): "관리자 모드" 표시 + 수정 기능 활성화

### 4. DB 보안
- RLS(Row Level Security) 정책 설정
- 읽기: 모두 허용
- 쓰기/수정/삭제: 관리자만 허용

## 구현 범위
1. Supabase Auth 설정
2. 사용자 프로필 테이블 생성 (user_profiles)
3. 로그인/로그아웃 페이지
4. 인증 컨텍스트 (AuthContext)
5. 보호된 라우트 (ProtectedRoute)
6. RLS 정책 업데이트
7. 기존 관리자 모드 버튼 제거

## 제외 사항
- 회원가입 기능 (관리자가 직접 DB에서 계정 생성)
- 비밀번호 재설정
- 소셜 로그인
