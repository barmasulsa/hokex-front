GA4 Property ID 확인 방법

1. Google Analytics 접속

  1. https://analytics.google.com/ 접속
  2. 왼쪽 하단 ⚙️ "관리" 클릭
  3. "속성" 열에서 현재 선택된 속성명 확인
  4. "속성 설정" 클릭
  5. 속성 ID 확인 (예: 538348093)

2. 현재 설정된 Property ID

538348093

3. Service Account 확인

hokex-analytics@hokex-498415.iam.gserviceaccount.com

4. 스크린샷에서 확인한 내용

  • ✅ Service Account가 이미 추가되어 있음
  • ✅ "뷰어" 역할 부여됨
  • ⚠️ Property ID가 일치하는지 재확인 필요

5. 다른 가능성

  • 잘못된 속성에 추가: 다른 GA4 속성에 권한을 추가했을 가능성
  • Service Account Key 문제: Supabase에 설정한 Key가 다른 Service Account의 것일 가능성
  • GA4 API 활성화: GCP 프로젝트에서 GA4 API가 활성화되어 있는지 확인

6. 확인해야 할 것

  1. GCP 콘솔에서 Service Account 확인
    • GCP IAM Service Accounts
    • Service Account 이메일이 정확히 hokex-analytics@hokex-498415.iam.gserviceaccount.com인지 확인
  2. Google Analytics Data API 활성화 확인
    • Analytics Data API
    • "사용 설정" 되어 있는지 확인
  3. GA4에서 정확한 Property에 권한 추가 확인
    • 관리 → 속성 → 속성 설정 → 속성 ID가 538348093인지 확인
    • 해당 속성의 "속성 액세스 관리"에 Service Account가 있는지 재확인
